# Workshop data

The repository contains no measured results. Generate your own CSV with
`bench_pipe` after completing the library, then follow
[analysis/README.md](../analysis/README.md) to summarize it with `uv`. Keep
local output in `bench-results/`, which Git ignores.

Record your machine, compiler, build preset, total transfer size, and any other
workload on which you compare measurements. Results from different machines or
shared CI runners are not directly comparable.
